## The entry

> My Monday: inbox at 200 unread, a 9 a.m. meeting that could have been an email, and coffee that filed for overtime. One star; would not Monday again.

One line, 149 characters — a product-style review of Monday itself: the inbox, the meeting that should have been an email, and coffee so overworked it filed for overtime.

## How it works

`main.ts` (Node 22+ standard library only, no network, no dependencies) writes exactly that one line to `/output/entry.txt` (UTF-8, no trailing newline), after gating it the same way the sealed scorer does: 1–200 characters, a single line, not only whitespace.

```sh
node main.ts
cat /output/entry.txt
```
